# 외부 데이터 교차검증

설치된 Palworld 데이터가 1차 기준이다. 외부 사이트는 이름, 아이콘과
표시 문구를 비교하는 2차 근거로만 사용한다. 사이트 값이 게임의 구조화
필드 또는 한국어 원문과 충돌하면 설치본 데이터가 이긴다.

## 발견한 외부 페이지 내부 불일치

같은 페이지의 파트너 스킬 설명은 “다른 거점 팰”의 “작업 적성 레벨
`+1`”이라고 표시한다. 반면 바로 아래 랭크 표는 이를 “거점의 모든 팰”,
“수작업 적성 `+1%`”로 표시한다.

로컬 설치본의 구조화 데이터는 아래와 같다.

- `TargetType1 = ToBaseCampPal`
- `bNotAssignSelf = true`
- `EffectType1 = WorkSuitabilityAddRank_Handcraft`
- `EffectValue1 = 1`
- `InvokeInBaseCamp = true`
- `IsStackablePartnerSkillBySameTribe = false`

구조화 필드와 한국어 원문이 함께 “다른 거점 팰의 수작업 레벨 +1,
중복 불가”를 지지한다. 따라서 웹앱의 정규화 결과는
`other_base_pals`, `suitabilityDelta = 1`, `stackable = false`를
유지한다. 외부 표의 “모든 팰”과 퍼센트 기호는 가져오지 않는다.

외부 페이지는 다섯 단계 배열을 랭크 `0`~`4`로 표시한다. 추출 JSON도
단순 값 배열 대신 각 값에 명시적인 `rankIndex`를 붙여 인덱스와 표시
레벨을 혼동하지 않게 수정했다.
