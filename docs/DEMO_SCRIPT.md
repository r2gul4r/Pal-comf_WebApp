## 재생성·검수

로컬 서버가 실행 중일 때 아래 명령으로 같은 영상을 다시 만든다.

```powershell
pnpm demo:record
```

영상 메타데이터와 0·5·10·15·20·25·30초 프레임을 Chromium으로 다시
디코딩해 확인한다.

```powershell
pnpm demo:review
```

Chrome 경로가 기본 설치 위치가 아니면 환경변수로 지정한다.

```powershell
$env:PLAYWRIGHT_CHROME_PATH = 'D:\path\to\chrome.exe'
pnpm demo:record
```

- 개인 Steam 계정명, 로그인 세션, 다운로드 폴더를 화면에 띄우지 않는다.
