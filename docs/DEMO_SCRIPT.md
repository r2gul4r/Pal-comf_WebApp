# 실행 영상 가이드

## 자동 생성 데모

- 영상: `output/playwright/pal-comf-demo.webm`
- 표지: `output/playwright/pal-comf-cover.png`
- 규격: 1440×900, 69.08초, 6,979,289 bytes, WebM
- 방식: 무음 화면 녹화 + 단계별 한국어 자막
- 내용: 수작업·핑토 역검색 → 장인 기질 노란 Rank 3 → 초절기교 파란
  Rank 4 → 악마의 손 세계수 Rank 5 → 지도 탭 → 30개 포인트 → 포인트 4
  좌표·source package → 휠 500% 확대 → 드래그 → 탭 상태 보존
- 화면 밖 콘텐츠는 각 대상의 중앙으로 부드럽게 스크롤한다. 검색 결과 카드와
  지도 상세를 한 화면에 억지로 구겨 넣지 않고 장면을 나눠 표시한다.

로컬 서버가 실행 중일 때 아래 명령으로 같은 영상을 다시 만든다.

```powershell
pnpm demo:record
```

영상 메타데이터와 0·12·24·36·48·58·68초 프레임을 Chromium으로 다시
디코딩해 확인한다.

```powershell
pnpm demo:review
```

Chrome 경로가 기본 설치 위치가 아니면 환경변수로 지정한다.

```powershell
$env:PLAYWRIGHT_CHROME_PATH = 'D:\path\to\chrome.exe'
pnpm demo:record
```

## 음성 설명을 덧붙일 때의 2~3분 순서

### 0:00–0:20 — 문제

화면: 웹앱 첫 화면

내레이션:

> 팰월드 1.0에서 원하는 거점 작업 효과는 알지만 어떤 특성이나 파트너
> 스킬이 그 효과를 주는지 역으로 찾기 어렵다. 이 도구는 현재 설치된 게임
> 데이터를 읽어 그 관계를 한 화면에서 검색한다.

### 0:20–0:45 — 데이터 기준

화면: 우측 Build ID와 하단 데이터 기준

내레이션:

> 외부 위키가 아니라 Steam Build 24181527의 Pal-Windows.pak이 1차
> 기준이다. 추출기는 원본을 수정하지 않고 필요한 DataTable과 아이콘만
> 읽는다. 현재 결과는 팰 16종, 작업 관련 효과 26개이며 내부 검증 오류는
> 0개다.

### 0:45–1:20 — 핵심 역검색

화면:

1. 작업 종류를 `수작업`으로 변경
2. 검색어에 `핑토` 입력
3. 핑토 카드의 `수작업 적성 +1`, `거점의 다른 팰`, `중첩 불가` 표시
4. 기본 작업 적성과 1~5성 수치 표시

내레이션:

> 수작업을 고르면 그 작업에 직접 연결된 파트너 스킬과 모든 작업에 적용되는
> 작업 속도 특성이 같이 나온다. 핑토를 검색하면 파트너 스킬이 다른 거점
> 팰의 수작업 적성을 1 올리고 중첩되지 않는다는 구조화 값이 보인다.

### 1:20–1:50 — 특성과 범위

화면:

1. 검색어 삭제
2. 스킬 종류를 `특성만`으로 변경
3. `장인` 검색
4. `장인 기질`, 작업 속도 `+50%`, 적용 범위 `해당 팰 자신` 확인

내레이션:

> 특성은 특정 팰을 임의로 연결하지 않는다. 게임 데이터에서 일반 특성 풀,
> 희귀 팰 특성, 세계수 팰 특성을 구분하고 자신 대상 작업 속도 수치를
> 보여준다.

### 1:50–2:15 — 특수 사례와 근거

화면:

1. 검색어 삭제
2. 작업 `관개`, 범위 `해당 팰 자신`
3. 플루미 또는 흘루미 카드의 발동 조건 확인
4. `게임 설명과 출처 보기` 펼치기

내레이션:

> 한 스킬에 효과가 여러 개면 효과 단위로 나눈다. 플루미처럼 내부 작업
> 타입이 둘이지만 같은 관개 효과인 경우는 중복을 합치고 원시 필드는
> 보존한다. 구조 필드와 한국어 원문이 충돌한 중첩 여부는 추측하지 않고
> 미확인으로 표시한다.

### 2:15–2:45 — AI 검증과 결론

화면: `docs/AI_WORKLOG.md`의 오류·수정 부분 또는 터미널 검증 결과

내레이션:

> AI가 처음에는 효과 대상과 발동 조건을 합쳤고, 설명 자리표시자 하나를
> 남겼으며, 최신 TypeScript와 린터 버전도 충돌했다. 실제 pak 필드,
> 한국어 원문, 컴파일러와 테스트 결과로 각각 수정했다. 최종적으로 lint,
> 타입 검사, 테스트 5개와 프로덕션 빌드를 모두 통과했다.

## 녹화 전 체크

- 개인 Steam 계정명, Nexus 세션, 다운로드 폴더를 화면에 띄우지 않는다.
- 게임 세이브 화면을 열지 않는다.
- 브라우저 배율을 100%로 둔다.
- `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build` 결과를 미리
  준비한다.
- 영상에 Build ID와 “게임 설치본 기준” 문구가 한 번 이상 보이게 한다.
