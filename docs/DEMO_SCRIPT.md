## 장면 순서

1. **0:00–0:10 — 자동화한 이유**
   정식 버전에 새 패시브와 스킬이 추가됐지만 인게임 검색이 없고, 기존 DB는
   팰을 하나씩 확인해야 했다는 불편을 설명한다.
2. **0:10–0:19 — 작업 효과 기반 팰 탐색**
   `목장` 작업 키워드를 선택하고 해당 작업 효과를 가진 팰·파트너 스킬·특성
   결과를 보여준다.
3. **0:19–0:27 — 패시브 정보 확인**
   스킬 종류를 `특성만`으로 바꾸고 `장인 기질`을 검색해 효과와 증가 수치를
   한 화면에서 보여준다.
4. **0:27–0:36 — 불길한 알 지도**
   같이 하는 친구들은 알을 다 찾았는데 사용자만 못 찾았다는 실제 불편과,
   30개 스폰 추첨 위치를 지도에서 확인하는 해결 화면을 보여준다.
5. **0:36–0:46 — 좌표 확인**
   포인트 #04를 선택하고 X·Y·Z 인게임 좌표가 바뀌는 장면을 보여준다.

추출기 내부, 패시브 Rank 검증, source package, 500% 확대 테스트, 빌드 명령은
동작 영상에서 제외한다. 과제의 AI 오류 검증과 기술 근거는 README와

## 재생성·검수

로컬 서버가 실행 중일 때 아래 명령으로 같은 영상을 다시 만든다.

```powershell
pnpm demo:record
```

영상 메타데이터와 0·6·12·18·24·30·36·42초 프레임을 Chromium으로 다시
디코딩해 확인한다.

```powershell
pnpm demo:review
```

Chrome 경로가 기본 설치 위치가 아니면 환경변수로 지정한다.

```powershell
$env:PLAYWRIGHT_CHROME_PATH = 'D:\path\to\chrome.exe'
pnpm demo:record
```

## 녹화 전 체크

- 개인 Steam 계정명, 로그인 세션, 다운로드 폴더를 화면에 띄우지 않는다.
- 게임 세이브 화면을 열지 않는다.
- 브라우저 배율을 100%로 둔다.
- 화면 밖 결과는 중앙으로 스크롤하고 자막이 핵심 카드나 좌표를 가리지 않게 한다.
